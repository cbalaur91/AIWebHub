# SEO & GEO Blog Post Checklist

## On-Page SEO

### Title Tag
- Include primary keyword
- 50-60 characters ideal
- Compelling — include year, number, or value proposition
- Matches H1 exactly or closely

### Meta Description (excerpt)
- 120-160 characters
- Contains primary keyword
- Includes a call to action or value proposition
- Unique per post

### Heading Structure
- Single H1 (the title)
- 5-8 H2 sections per 1,500+ word post
- H2s include keywords naturally — at least 3 of them
- Question-based H2s preferred (matches search queries and AI extraction)
- No skipping heading levels

### Keyword Placement
- Primary keyword in: title, first 100 words, 2-3 H2s, last paragraph
- Secondary keywords spread naturally throughout
- Semantic variations used (synonyms, related phrases)
- Density 1-3% — never forced or stuffed

### Internal Linking
- 2-4 internal links per post
- Descriptive anchor text (not "click here")
- Link to relevant service pages, other blog posts, contact page
- Spread throughout the content, not clustered

### Content Length
- Blog posts: minimum 1,500 words
- Pillar content: 2,500-4,000 words
- Each section: 150-300 words

## GEO (Generative Engine Optimization)

### Citability
- Self-contained answer blocks: 134-167 words each
- Answer-first formatting: direct answer in first 40-60 words of section
- Definition patterns: "X is [definition]" for core concepts
- Quotable facts with specific numbers and sources

### Structural Readability
- Clean heading hierarchy
- Short paragraphs (2-4 sentences)
- Bulleted/numbered lists for processes and comparisons
- Tables for comparative data
- FAQ-style question headings

### Authority Signals
- Author byline with credentials
- Publication date and last modified date
- Citations to primary sources and real data
- Specific examples with verifiable details

### AI Crawler Accessibility
- Content rendered server-side (SSR/SSG)
- No critical content behind JavaScript-only rendering
- Clean semantic HTML structure

## E-E-A-T for Blog Posts

### Experience (20%)
- First-person signals: "we've built", "in our experience", "working with clients"
- Real project references (with permission)
- Process documentation showing actual methodology
- Before/after results where available

### Expertise (25%)
- Technical accuracy — use correct terminology
- Current data — include the year, reference recent developments
- Depth appropriate to the audience
- Claims supported by evidence

### Authoritativeness (25%)
- Author credentials in byline
- Consistent publication history
- References to real tools, companies, industry standards
- Original insights beyond what competitors publish

### Trustworthiness (30%)
- Transparent about pricing and limitations
- No exaggerated claims
- Contact information accessible
- Content regularly updated (modifiedDate)

## Common Mistakes to Avoid

- Generic openers ("In today's digital landscape...")
- Fabricated statistics without sources
- Keyword stuffing in headings
- All links clustered in one section
- Sections that restate the same point
- Missing CTA or weak closing paragraph
- Not checking if the topic overlaps with existing posts
- Ignoring the existing blog's voice and tone
